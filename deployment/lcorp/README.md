# LCORP private FC runtime

These files are the application overlay used by the private LCORP function. Assemble with the shared Timesheet adapter from deployment/fc, the QRCode dependency, and the private site snapshot. The public Pages site has its own demo snapshots and static hosting workflow. Production datasets, environment settings, and credentials are maintained in the deployment environment.

The separately deployed Ops roadmap code is under deployment/ops-roadmap/live. Its private source snapshot is supplied at deployment as site/data.json.
